# 🚀 B-TECH Executive Sales & Performance Dashboard (Power BI)

An ultra-modern, fully custom-designed executive business intelligence dashboard built entirely inside **Power BI** utilizing **Advanced DAX, Embedded HTML/CSS, and SVG Vector Graphics** for high-performance visual storytelling.

---

## 🌟 Dashboard Architecture & Pages

The dashboard is structured into 4 cohesive, dark-mode analytical views tailored for executive decision-making:

1. **Overview Page (Executive Summary):** 
   * Real-time KPI cards tracking Total Sales, Net Profit, Orders, AOV, and Profit Margins with dynamic YoY growth indicators.
   * Interactive Donut visual displaying Sales by Category with smooth custom SVG animations.
   * Monthly Sales vs Previous Year performance tracking.

2. **Regional Analysis:**
   * Geospatial performance tracking across Egyptian regions (Greater Cairo, Delta, Alexandria, South).
   * Regional breakdown matrix comparing Sales, Profit, and Quantities.

3. **Categories & Profit:**
   * Detailed profitability matrix for categories (`Office Supplies`, `Technology`, `Furniture`).
   * Cross-analysis of Category vs Region profitability and Customer Segment contribution (`Consumer`, `Corporate`, `Home Office`).

4. **Top Products & Executive Summary:**
   * High-performance ranking of actual top-performing products (`Product Name`).
   * Company-wide health check metrics and operational efficiency tracking.

---

## 🛠️ Key Technical Highlights

* **Advanced DAX:** Complex measure modeling using `ADDCOLUMNS`, `SUMMARIZE`, `RANKX`, `CALCULATE`, and dynamic YoY growth calculations.
* **HTML/CSS Visual Integration:** Bypassing standard Power BI visuals limitations by rendering fully responsive cards, grids, progress bars, and hover effects using custom HTML visual containers.
* **Dynamic Animations:** Implemented CSS keyframes (`popIn`, `sweep`, `blink`, `fillBar`) for a fluid user experience mimicking web applications.
* **Color Palette & Theme:** Custom Dark Mode theme (`#111827` background) with sleek neon-orange gradients (`#FF5500`) matching modern enterprise UI/UX design standards.
